整理日期：2026-11-27（`main` 在 `6ca4aab`，组件与样式、模板刚合进去）。

起因：用户提了六条——右键菜单和快捷键（比如按住 Alt 拖动复制图层、画板）、幻灯片和图层做成选项卡并且能拖出来变成单独的面板、形状的顶点圆角（像 Illustrator 那样在画布上拖）、智能参考线和辅助线、浮动面板（像 Photoshop 那样把图片调整单独放在一个浮动面板里）、支持 UI 界面设计——并且要求不局限于这六条，把操作细节整体重新规划一遍。

## 1. 统一的操作规则

下面这些规则贯穿后面所有的条目，先定下来，各处照着做，用户学一次到处能用。

### 1.1 一切操作都是命令

按钮、顶部菜单、右键菜单、快捷键、命令面板都只引用命令 id（现在的按钮和快捷键已经是这样）。所以：

- 每个命令都要有 `enabled`，界面靠它把做不了的项变灰，而不是点了没反应。
- 做不了的原因由命令返回一个原因 id（比如 `instance-structure`：实例里的结构跟着主组件），界面翻译成悬停提示。内核仍然不产生给人看的文字。
- 右键菜单、顶部菜单、命令面板共用一份菜单项定义（见 [CTX-1](#ctx-1-菜单的补充)），不会出现"右键里有、菜单里没有"。

### 1.2 修饰键的含义

| 键                   | 含义                     | 用在哪里                                                                                                                     |
| -------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Shift                | 约束                     | 移动锁定在 0° / 45° / 90°；缩放等比；旋转按 15°；画矩形、椭圆是正方形、正圆；钢笔、直线按 45°；列表里连选；画布上加选或减选  |
| Alt（Option）        | 复制，或者"从中心、单独" | 拖动对象、画板、图层、幻灯片时复制一份；缩放、画形状从中心往外；拖圆角控件只改这一个角；悬停时测距离；钢笔拖控制柄时断开对称 |
| ⌘（Windows 是 Ctrl） | 穿透、暂停               | 单击直接选中编组里面的对象；框选只选组里的成员；拖动中暂停吸附；缩放画框、画板时里面的东西不按约束跟着变                     |
| 空格                 | 移动视图或正在画的东西   | 平时按住是抓手（已有）；画形状、框选、拖动的过程中按住，挪动的是正在画的那个东西                                             |
| Esc                  | 一层层退出               | 先取消正在进行的拖动（回到拖动前），再退出当前模式（编辑文字、调整填充、画路径），最后取消选区                               |

- 拖到一半按下或松开修饰键立即生效，不用再动鼠标（已有，见 architecture.md 的"输入与快捷键"一节）。比如拖动时先没按 Alt，中途按下就变成复制，再松开又变回移动，原件回到拖动的位置。
- 在 Windows 的浏览器里，Alt 加字母可能被浏览器占用（Chrome 的 Alt+D 是地址栏、Alt+F 是菜单），要逐个实测；被占用的换别的键，桌面版（Electron）没有这个问题。
- Windows 上 Ctrl+Alt 等于 AltGr，有的键盘布局用它打字符。`mod+alt` 组合（⌥⌘K 这类）照常用，Figma 也是这样，但要知道这个限制。

### 1.3 反馈

- 拖动时在鼠标旁边显示数值：画形状、缩放显示"宽 × 高"，旋转显示角度，拖圆角显示半径，拖辅助线显示位置。选中对象时选区框下面常驻一个"宽 × 高"的小标签（UI 设计时很有用，可以在视图菜单里关掉）。
- 正在拖动时，画布底部显示一行修饰键提示（"Shift 锁定方向 · Alt 复制 · ⌘ 不吸附"），第一次用的人不用查文档。可以关掉。
- 拖动开始后，不相关的手柄（圆角控件、动作路径）先隐藏，松手再出来。

### 1.4 偏好和布局存在哪里

- 文档里的东西（辅助线、版面网格、约束、自动布局、圆角）存进文档，走事务，可以撤销，跟着文件走。
- 只和这台电脑、这个人有关的东西（面板布局、吸附开关、标尺显不显示、自定义快捷键）存在浏览器的 localStorage 里，读写都包在 try/catch 里（照 `Sidebar.tsx` 现在的写法），存不了就只在这次打开里有效。

算式、拖标签改数值、颜色的吸管和色板、rgb / hsl 输入、分区折叠、对齐到画框已经有了，见 architecture.md 的"属性面板的输入控件"一节。还没有的：

### INSP-1 数字输入框的补充

- 多选时值不一样（"混合"）的框上拖标签，每个对象各自加减（现在从 0 开始，拖完都变成同一个值）：要让调用方提供"按差值改"的函数。

### INSP-2 颜色的补充

- 没有 `EyeDropper` 的浏览器（Safari、Firefox）退回成只在画布上取色（从渲染结果里读像素）。
- 颜色选择器换成自己画的（色相环、饱和度亮度方块、透明度条），不再用浏览器自带的 `<input type="color">`。

## 10. 工具、路径和圆角

### TOOL-1 工具栏的补充

工具栏分组和锁定、直线和箭头（含端点样式）、多边形和星形、铅笔、吸管、视图缩放、等比缩放已经有了，见 architecture.md 的"工具"一节。还没有的：

- 放图片按钮移到工具栏里文本的后面（快捷键 ⇧⌘K 已经有了）。
- 铅笔的容差可调（现在固定是屏幕上 2.5 像素），以及按住 Alt 画直线段、画的时候按住 Shift 接着选中的开放路径往下画。
- 多边形、星形在画布上拖一个控件改边数和内径（Illustrator 的星形工具画的时候按上下方向键加减角数）。
- 箭头的样式再多几种（菱形、空心三角、空心圆），以及箭头大小单独可调；现在只跟着线宽变。打开 SVG、PDF 时箭头是两个对象（线和箭头），认不回箭头样式。

### PATH-1 直接选择工具的补充

直接选择工具（A，改锚点）和钢笔在选中路径上加删锚点已经有了，见 architecture.md 的"直接选择工具"一节。还没有的：

- 动作路径的锚点也用它改（[ANIM-1](backlog.md#anim-1-动作路径的补充)）：现在动作路径只能拖锚点和控制柄，不能加删锚点、切换尖角平滑。
- 锚点的右键菜单（删除锚点、转成尖角 / 平滑、在这里断开、连接两个端点、闭合路径、圆角…）。
- 只在选中的锚点上出圆角控件（现在直接选择工具里不画圆角控件）。
- 矩形、椭圆转成路径时底部提示一下；现在转换和挪锚点是两步撤销。
- 钢笔停在锚点、线段上时的指针现在用浏览器自带的"加号"和"禁止"，可以换成钢笔带加减号的图标。

### CORNER-1 顶点圆角的补充

矩形四个角分别设、路径尖角的圆角、三种样式、平滑度、画布上的圆角控件和属性面板已经有了，见 architecture.md 的"顶点圆角"一节。还没有的：

- 一边或两边是曲线的角（Illustrator 支持）：要在曲线上按弧长找切点再拆开曲线。现在这种锚点不出控件，半径不起作用。
- 双击控件弹出一个小面板（输入半径、选样式、调平滑度）；现在在属性面板里改。
- 直接选择工具里只在选中的锚点上出控件（[PATH-1](#path-1-直接选择工具的补充)）。
- 多选时也显示控件、拖一个改全部。
- 平滑度是近似：把切点往两边推、控制柄往顶点拉，和 Figma 的算法不完全一样；打开 Figma 导出的 SVG 时也认不出平滑度。
- 打开 PDF 时只认四个角一样的圆角矩形。

## 11. UI 界面设计

对应用户的第 6 条。现有的组件、颜色和文字样式是基础，还缺下面这些。顺序就是建议的做法顺序。

### UI-1 画框的补充

画框（新节点类型 `frame`：填充、描边、圆角、裁剪内容，可以嵌套）、画框工具 F、⌥⌘G 用画框包起来、拖进拖出画框已经有了，见 architecture.md 的"画框"一节。还没有的：

- 画布上在画框的左上角显示名字（Figma 在顶层画框上显示），点名字选中画框。
- 编组里的画框不能当"放进去"的目标（`containerAt` 只顺着画框往里找，不进编组）。
- 吸附：画框里的东西拖动时吸到画框的边和中线、吸到同一个画框里的其他东西（现在吸附的候选是画板和页面的直接子节点）。
- 画框里的东西不能单独加动画（和编组一样，动画只加在幻灯片的直接子节点上）。
- 打开 PDF、SVG 时认不回画框（读回来是一个填充的矩形、裁剪过的内容和一个描边的矩形）。
- 自动布局（[UI-3](#ui-3-自动布局的补充)）、版面网格（[UI-5](#ui-5-版面网格的补充)）挂在画框上。

### UI-2 约束的补充

约束（靠左、靠右、左右、居中、按比例，上下同理）、改画框和画板大小时按约束跟着变、按住 ⌘ 不变、属性面板的约束小图已经有了，见 architecture.md 的"约束"一节。还没有的：

- **组件实例按约束改大小**（[PROD-1](backlog.md#prod-1-组件与样式的补充)）：现在实例只能整体缩放（缩放写在变换矩阵里），非等比拉伸时文字被拉扁。要加"按约束"的缩放方式（组件面板里切换，默认还是整体缩放）：底板拉伸、文字不变。难点在组件同步：按约束挪出来的位置和大小要么记成覆盖（那样主组件改了几何就不跟着变），要么同步时按实例的大小重新套一遍约束（要让同步认得约束），先想清楚再做。
- 选中对象时在画布上画出约束：从对象到它靠着的边画虚线（Figma 的做法），一眼看出它会怎么跟着变。
- 约束小图在多选、几个对象不一样时只亮第一个的，可以改成亮的地方用半透明表示"有的是"。
- 等比缩放工具（K）拖的是画框时，现在里面的东西整体按比例变；可以加一个选项按约束变。

### UI-3 自动布局的补充

自动布局（方向、间距、内边距、对齐、两端对齐、包住内容、填满、不参与，⇧A / ⌥⇧A，拖动调整顺序和拖进拖出，和组件一起用，字体晚到后不进历史地重新排）已经有了，见 architecture.md 的"自动布局"一节。还没有的：

- **换行**：横排放不下时换到下一行，行间距单独设。
- **画布上直接调**：鼠标停在自动布局画框上时，间距和内边距的区域显示成粉色，可以直接拖改数值（Figma 的做法）；现在只能在属性面板里改。
- 最小、最大宽高（填满时不小于、不大于多少）。
- 文字的基线对齐（横排时几段字号不同的文字按基线对齐）。
- 子对象的层叠顺序：现在排在前面的在下层，可以加"排在前面的在上层"的开关（做重叠的头像列表时用）。
- 拖动调整顺序时，其余的子对象实时让出位置（现在只画插入条，松手后才排）。
- 多选几个子对象一起拖时按它们原来的先后插在一起（现在每个各自按自己的中心算位置）。
- 组件实例按约束改大小（[UI-2](#ui-2-约束的补充)）之后，实例里的自动布局按实例的大小排。

### UI-4 阴影和模糊的补充

投影、内阴影、图层模糊、背景模糊（可以叠好几个，画布、导出 SVG、导出 PDF、播放器都画）已经有了，见 architecture.md 的"效果"一节。还没有的：

- **背景模糊在网页和 SVG 里**：SVG 做不了，播放器里可以给图层套 CSS 的 `backdrop-filter`（图层要单独成一个元素，按轮廓裁剪）；导出 PDF 时可以把对象下面的画面也画进图片里再模糊（现在只剩对象本身）。
- 效果样式：像颜色样式一样，存一套阴影反复用（做卡片、按钮时常用）。
- 效果列表拖动排序；阴影颜色链接颜色样式。
- 投影的"只在对象外面显示"开关（对象半透明时阴影不从里面透出来，Figma 有这一项）。
- 画板上的效果（现在画板不画效果）。

### UI-5 版面网格的补充

列、行、方格网格（⇧G 开关、吸附到列和行的边、导出不画）已经有了，见 architecture.md 的"版面网格"一节。还没有的：

- 网格样式：像颜色样式一样存一套网格（比如"12 列桌面"），在几个画板上共用。
- 缩放画框时子对象按列吸附宽度（拖对象的边吸到列边已经有了，按"占几列"改宽度还没有）。
- 方格网格也吸附（现在太密，只画不吸）。
- 版面网格跟着自动布局的内边距走（Figma 的做法）。

### UI-6 原型的补充

点击跳到某一页、回到上一页、指定过渡效果、画布上的连线箭头已经有了，见 architecture.md 的"原型"一节。还没有的：

- **拖线连接**：选中对象后从它右边拖出一根线连到目标画板（Figma 的做法）；现在在属性面板的下拉里选，画布上的箭头只是显示。
- 悬停、按下、拖动等触发方式；打开外部链接、显示叠层（弹窗）等动作。
- 滚动区域（画框里的内容超出时可以滚动）、固定在顶部的元素、悬停状态。
- 进入动画还没播出来的对象上的热区现在也点得中（热区不跟着图层的显示隐藏）。
- 在手机上预览原型（[UI-9](#ui-9-以后)）。

### UI-7 标注和交付的补充

检查面板（尺寸、位置、颜色、文字、CSS）、复制为 CSS、导出设置和"导出全部"已经有了，见 architecture.md 的"检查和交付"一节。还没有的：

- iOS（SwiftUI）、Android（Compose）的写法，可以在检查面板里切换。
- 检查面板里点颜色、数字就复制那一项；颜色链接了颜色样式时显示样式名。
- 导出设置的预览（缩略图和文件大小）；导出时选保存到一个文件夹而不是 ZIP（浏览器支持 `showDirectoryPicker` 时）。
- 非画板对象导出 PDF（现在 PDF 只对画板）。

### UI-8 素材和起步的补充

界面的屏幕尺寸、画框工具的预设、lucide 图标库、登录页模板已经有了，见 architecture.md 的"界面设计的素材和起步"一节。还没有的：

- 更多界面模板：设置页、卡片列表、仪表盘、落地页。
- 图标库按类别浏览（lucide 有分类数据），中文名搜索，最近用过的图标。
- 图标的粗细、大小在放之前选（现在放上去以后再改描边）。
- 要加别的图标库先核实许可能不能商用。

### UI-9 以后

- 组件的变体和组件属性（一个按钮组件有"主要 / 次要""正常 / 禁用"几种状态）。
- 变量（设计令牌）：颜色、数字变量，可以有亮暗两套值，切换整份设计的主题。现有的颜色样式可以升级过去。
- 在手机上预览原型。

## 13. 建议的顺序

每一步是一个分支（`feature/xxx`），单独可以用。和 backlog 里已有的几项有交叉：[EDIT-4](backlog.md#edit-4-段落样式的补充)、[PROD-1](backlog.md#prod-1-组件与样式的补充) 的快捷键问题（要按 `event.code` 匹配）已经解决；PROD-1 的约束和自动布局、[PROD-2](backlog.md#prod-2-模板的补充) 的母版都依赖 UI-2 的约束；PROD-2 里"画布视图里新建画板"由 TOOL-1 的画板工具和画布的右键菜单解决；[ANIM-1](backlog.md#anim-1-动作路径的补充) 的锚点编辑和 PATH-1 一起做。

1. **地基**：[F-4](#f-4-补齐命令) 里剩下的命令，跟着用到它们的功能一起做。
2. **右键菜单、菜单栏、快捷键**：[CTX](#3-右键菜单和顶部菜单)、[MENU](#menu-1-顶部菜单栏的补充)、[KEY](#4-快捷键和修饰键)、[SEL](#6-选择和变换) 里剩下的，大多跟着别的功能一起做。
3. **吸附和参考线**：[SNAP](#7-吸附参考线标尺) 里剩下的。
4. **面板系统**：[DOCK](#5-面板选项卡停靠浮动) 里剩下的，以及 [LAYER-1](#layer-1-图层面板的补充)、[SLIDE](#slide-1-幻灯片条的补充) 里剩下的。
5. **路径和圆角**：[PATH-1](#path-1-直接选择工具的补充)、[CORNER-1](#corner-1-顶点圆角的补充) 里剩下的。
6. **UI 设计**：[UI-1](#ui-1-画框的补充) 画框 → [UI-2](#ui-2-约束的补充) 约束 → [UI-4](#ui-4-阴影和模糊的补充) 阴影 → [UI-3](#ui-3-自动布局的补充) 自动布局（最难，先做原型）→ [UI-5](#ui-5-版面网格的补充) 版面网格 → [UI-7](#ui-7-标注和交付的补充) 标注 → [UI-6](#ui-6-原型的补充) 原型。

## 14. 验证

- 纯逻辑放在不依赖浏览器的地方，用单元测试在 Node 里测：剪贴板的序列化和放置规则、吸附的查找、面板布局的变换、圆角几何、自动布局的算法、快捷键匹配。
- 几何和渲染相关的（圆角、画框的裁剪、阴影）照现有做法和导出的 PDF、SVG 逐像素比较，写明差异有多大、差在哪。
- 右键菜单、面板拖动、吸附、Alt 复制在浏览器里用真实的鼠标和键盘事件实测（面板拖动用指针事件实现，自动化工具能驱动）。开发版里 `window.shiba` 是编辑器实例，可以在控制台里造数据。
- 快捷键和剪贴板在 Chrome、Safari、Firefox 里表现不一样的地方多，这几项至少三个浏览器各试一次；只在 Chromium 内核里验证过的，在 architecture.md 里写明。
